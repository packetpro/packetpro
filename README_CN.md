# PacketPro

**PacketPro** 是一款面向 **iOS / macOS** 的 **HTTP / HTTPS 网络抓包与请求重写工具**，专为开发者、测试人员和高级用户设计。

无需越狱，基于官方系统 API，实现强大且可控的网络调试能力，所有数据 **仅保存在本地**。

> 抓包 · 分析 · 重写  
> 无需越狱 · 隐私优先 · 专业级工具

---

## ✨ 核心功能

### 🔍 HTTP / HTTPS 抓包
- 实时捕获 App 与系统的网络请求
- 支持 HTTPS（通过本地证书信任）
- 查看完整请求信息：
  - URL / Method
  - 请求头（Headers）
  - 查询参数（Query）
  - 请求体 / 响应体（Body）

---

### ✏️ 请求 / 响应重写（Rewrite）
PacketPro 提供 **基于规则的请求与响应修改引擎**：

- 请求 Header 重写
- 请求 Body 重写
- 响应 Body 重写
- 支持按域名 / 路径 / Method 等条件过滤
- 多规则顺序执行

适用于：
- API Mock
- 后端 Bug 复现
- 功能测试
- 本地联调验证

---

### 🧠 过滤规则系统
- 精确匹配 / 包含匹配
- 多条件组合
- 规则一键启用 / 禁用
- 可复用规则模板

---

### 🔐 无需越狱
- 基于 Apple Network Extension 框架
- 使用官方 API
- 不依赖私有接口
- 符合 Apple 安全与隐私规范

---

### 🛡️ 隐私优先
- 所有网络数据 **仅保存在本地**
- 不上传、不分析、不追踪
- 无账号、无云端服务
